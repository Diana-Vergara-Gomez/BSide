# BSide 🎵

Blog de música enfocado en novedades semanales, conciertos y throwback (TBT) de álbumes y canciones.

## Descripción del proyecto

BSide es un blog dedicado a mantener a los lectores al día con lo último en música, cubriendo lanzamientos semanales, cobertura de conciertos y segmentos retro donde revisitamos álbumes y canciones icónicas del pasado.
